# SIH26043 Challenge Platform - Demo Walkthrough Script

## Overview
This script outlines the demonstration flow for the SIH26043 challenge platform.

1. **Organization Flow**:
   - Register/Login as an Organization.
   - Publish a new challenge statement with skills required & problem breakdown.
   - Monitor incoming team submissions.

2. **Contributor Flow**:
   - Register/Login as a Student/Contributor.
   - Browse challenges, filter by difficulty & required skills.
   - Form/Join a team with matching skill requirements.
   - Submit final solution (GitHub repo link, live demo URL, documentation).

3. **Evaluation & Award Flow**:
   - Organization/Admin reviews submitted solutions and marks acceptance status.
